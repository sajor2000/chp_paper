# JAMA Health Forum Submission Checklist

No item is passed by default. Each row requires a named human verifier, date, evidence
artifact, and issue-ledger disposition before submission.

| Domain | Required verification | Status | Human verifier | Date |
| --- | --- | --- | --- | --- |
| Journal instructions | Live JAMA Health Forum instructions rechecked within 30 days | checked_2026-07-15 | Direct official page | Recheck if submission occurs after 2026-08-14 |
| Article limits | Title, Key Points, abstract, main text, displays, and references within limits | not_assessed |  |  |
| Reporting guideline | STROBE, RECORD, STROBE-Equity, and SAGER crosswalk complete | not_assessed |  |  |
| Ethics | IRB, waiver, consent, and privacy language match approvals | not_assessed |  |  |
| Data provenance | Dataset manifest, lineage, checksums, and source contracts reconcile | not_assessed |  |  |
| Number ledger | Every number resolves to a frozen artifact and independent verification | not_assessed |  |  |
| Claim ledger | Every material claim has verified Paperclip or official-source support | not_assessed |  |  |
| Statistical review | Models, diagnostics, uncertainty, sidedness, and multiplicity reviewed | not_assessed |  |  |
| Equity review | Race, ethnicity, geography, and equity language reviewed | not_assessed |  |  |
| Displays | Tables and figures reconcile with text and use editable/vector outputs | not_assessed |  |  |
| Disclosure | Funding, conflicts, data sharing, code sharing, and AI-use disclosure complete | not_assessed |  |  |
| Final read | Human scientific, statistical, JAMA style, and read-aloud passes complete | not_assessed |  |  |
