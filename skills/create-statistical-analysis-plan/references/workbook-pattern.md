# Workbook Pattern

The pattern is derived from the user-provided `SBTSAP_Analysis_Plan_v4.xlsx` without copying its study content.

## Front sheets

`Overview` starts directly with these headers: Analysis; Claim; Unit of Analysis; Data File(s); Analysis Question; Primary Method; Secondary Methods; Site Script.

`Outputs` starts directly with: Output File; Subfolder; Dataset / Cohort Scope; Script Section; Contents; Role at Coordinating Center; Interpretation. Insert a dark-blue full-width band before each output family.

`Master Variables` uses two full-width note rows, then: Category; Variable; Description; Type; Format / Values; File; analysis-membership columns; Notes / Resolved Decisions. Color only the Category cell with a restrained, accessible pastel keyed consistently by category.

## Style

- Font: Calibri 10.
- Header/section blue: `#1F4E79`; white bold text.
- Alternate rows: white and `#F2F2F2`.
- Borders: thin `#D9E1F2`.
- Freeze the header region; enable filters on table headers.
- Wrap long text and use top vertical alignment.
- Use descriptive widths rather than global autofit. Keep identifier columns narrow and interpretation columns wide.
- Avoid cover sheets, merged decorative titles, empty default sheets, and decorative charts.

Scientific annexes may use a merged title row and a short instruction row because they are governance records, but their tables retain the same header language.
